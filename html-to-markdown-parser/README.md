# HTML to Markdown Parser

A modular HTML-to-Markdown converter optimized for LLM readability.

## Components

- Node-based tree architecture for HTML representation
- BeautifulSoup for parsing
- Clean output focused on LLM consumption

## Setup

```bash
pip install -r requirements.txt
```

## Current Status

This project is under development. Currently implemented:

- `Node` class: Basic representation of HTML elements
- `clean_html()`: Function to strip scripts, styles, and comments from HTML

More functionality will be added incrementally.
